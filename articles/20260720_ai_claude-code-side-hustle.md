# Claude Codeの副業、稼ぎ方は主に3パターン

FIREを目指すと言いながら具体的な行動が何も伴っていないワイにとって、「Claude Codeで副業」というワードはもはや検索するたびに罪悪感と期待が同時に押し寄せてくる。とはいえ調べもせずに諦めるのもさすがに情けないので、今日は本気で「稼ぎ方」の実態を掘り下げてみることにした。

## 3行サマリー

- Claude Codeを使った副業は、国内では主に「スキル販売型」「業務自動化支援型」「情報発信型」の3パターンに分類される
- 海外ではコンテンツの再編集や提案書作成代行など、投稿から初受注までが早い方法が紹介されている
- AIアシスタント(ClaudeやGPTなど)を使うフリーランサーは、使わない人より時給が47%高いというデータもある

## 国内で紹介されている3つの稼ぎ方パターン

- **スキル販売型**: クラウドソーシングで自動化スクリプトやツールを作成・販売。相場は1件5,000〜30,000円程度
- **業務自動化支援型**: 中小企業向けに請求書処理・データ集計・レポート作成といった定型業務をClaude Codeで自動化。月額3万〜10万円の継続契約になりやすい
- **情報発信型**: ブログやnoteなどでの情報発信・コンテンツ収益化

「継続契約」という言葉を見た瞬間に目が輝いてしまうの、副業初心者あるあるだと思う。単発より安定収入の方が魅力的に見えるのは当然だけど、まずは実績作りからだろうなというのは冷静に理解している。

## Web制作代行の具体的な単価感

- 典型的な流れは、顧客ヒアリング→要件を日本語でClaude Codeに指示→HTML/WordPressテンプレートを生成→微調整→継続保守、というもの
- シンプルなランディングページなら3万〜5万円、小規模なWebサイト制作で5万〜15万円程度が相場とされる
- 保守契約まで結べれば、単発の制作費に加えて継続収入にもつながる

## 海外で人気の"早く現金化できる"アプローチ

- 海外で紹介されているのは、フリーランスのライティング・編集代行、既存コンテンツの再編集(リパーパシング)、他のフリーランサー向けの提案書作成代行、リサーチ・要約代行、AIアシスタント型の仮想アシスタント業務など
- 特にコンテンツ再編集と提案書作成代行は、「投稿してから初受注までが早い」方法として紹介されている。フリーランサーや小規模事業者がすでに困っている課題を直接解決するタイプの仕事だからだという
- 1日1〜2時間の取り組みで、日給20〜100ドル程度が現実的な目安とされる
- 高収益の例として、あるクリエイターがClaude Code関連のスキル集(1本99ドル)を約50日で5,000ドル以上売り上げたケースも紹介されている

## フリーランサーの時給が47%高くなるというデータ

- AIアシスタント(中でもClaudeとGPTが最も多く挙げられている)を活用するフリーランサーは、活用しない人と比べて時給が47%高いというデータが紹介されている
- ただし実際に安定して稼いでいる人の多くは、派手な自動化そのものを売っているわけではなく、「サービスを販売し、その作業の大部分をClaude Codeにやらせる」という地味な組み合わせを実践しているという指摘もある

「AIを使えば自動的に稼げる」という夢のある話を期待して調べたのに、結局「地道にサービスを売る」という現実に着地するの、副業探しあるあるすぎて笑ってしまった。

## 転:結局「何を売るか」の方がAIの使い方より本質では

Claude Codeという強力な道具があっても、それ自体が収益を生むわけではなく、あくまで「誰の、どんな課題を解決するか」が先にある。スキル販売にせよ業務自動化支援にせよ、紹介されている成功パターンはどれも「AIで何ができるか」ではなく「誰が何に困っていて、それをどう解決して対価をもらうか」から逆算されているように見える。

## まとめ

- 国内の代表的な稼ぎ方は「スキル販売型」「業務自動化支援型」「情報発信型」の3パターン
- Web制作代行ならLP3〜5万円、小規模サイト5〜15万円程度が相場、保守契約で継続収入にもなる
- 海外ではコンテンツ再編集・提案書作成代行など、早期に現金化しやすい方法が人気
- AIアシスタントを使うフリーランサーは時給が47%高いというデータもあるが、本質は「地道なサービス販売+AIによる作業代行」
